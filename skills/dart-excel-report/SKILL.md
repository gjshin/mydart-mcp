# DART 데이터 → 엑셀 산출물

mydart-mcp가 돌려준 JSON을 리뷰 가능한 엑셀로 옮긴다.
핵심은 **셀만 보고 어디를 검증해야 하는지 알 수 있게** 만드는 것이다.

---

## 1. mydart-mcp 응답을 표로 옮기기

도구가 돌려주는 구조를 알고 있어야 변환 코드가 짧아진다.

### `get_financial_statements` — 단일 회사 전체 재무제표

```python
{
  "corp_code": "00126380", "bsns_year": "2025", "fs_div": "CFS", "currency": "KRW",
  "accounts": [
    {"sj": "손익계산서", "account": "매출액", "detail": None,
     "current": 300870903000000, "prior": 258935494000000, "prior2": 302231360000000},
    ...
  ]
}
```

**금액은 이미 정수다.** `"300,870,903"` 같은 문자열이 아니므로 파싱이 필요 없다.
`None`은 해당 기수에 값이 없다는 뜻이니 `0`으로 바꾸지 말고 빈 칸으로 둔다.

한 번 호출로 **3개년(당기·전기·전전기)**이 온다. 5개년이 필요하면 2회 호출해 겹치는
해로 이어 붙인다 — 겹치는 해의 값이 다르면 소급재작성이 있었다는 뜻이므로
**덮어쓰지 말고 그 사실을 시트에 남긴다.**

### `compare_financials` — 여러 회사 주요계정

```python
{"companies": [{"corp_name": "NAVER",
                "accounts": {"매출액": {"current": ..., "prior": ...}, ...}}, ...]}
```

### `get_periodic_report_item` — 다년도 항목 (타법인 출자현황 등)

```python
{"count": 12, "rows": [{"bsns_year": "2021", ...}, ...], "empty_years": ["2025"]}
```

행마다 `bsns_year`가 붙어 있어 그대로 피벗하면 연도별 표가 된다.
`empty_years`는 **누락이 아니라 공시가 없는 해**이므로 시트에 주석으로 남긴다.

## 2. 글자색 = 데이터 출처 (가장 중요)

재무모델 산출물의 공통 규약이다. 리뷰어가 **색만 보고 검증 대상을 판단**하므로
임의로 바꾸지 않는다.

```python
FONT_COLORS = {
    "formula":    "000000",   # 검정 — 수식 계산값        → 로직만 검증
    "hardcoded":  "FF0000",   # 빨강 — 외부 원본 데이터    → 원천과 대사 필요
    "assumption": "FFC000",   # 노랑 — 가정 입력          → 타당성 협의 필요
    "link":       "008000",   # 초록 — 타 시트 참조        → 링크 무결성 확인
}
```

**DART에서 받은 숫자는 전부 빨강(hardcoded)이다.** 외부 원본이기 때문이다.
거기서 계산한 증감률·비율·합계는 검정(formula)이어야 한다.

가정 셀은 노란 글자만으로는 잘 안 보이니 배경을 함께 준다:
`PatternFill("solid", fgColor="FFF2CC")`

---

## 3. 수식으로 연결한다

- **Summary는 Detail을 `SUMIFS`로 참조한다.** 파이썬에서 계산한 값을 Summary에
  붙여넣지 않는다. Detail이 바뀌면 Summary가 따라와야 한다.
- **모든 나눗셈은 `IFERROR`로 감싼다.** `#DIV/0!`을 노출하지 않는다.

```python
# 권장
ws["G10"] = '=IFERROR(SUMIFS(Detail!$E:$E, Detail!$B:$B, $B10, Detail!$C:$C, G$8), 0)'
ws["H10"] = '=IFERROR(G10/G$5, "")'

# 금지 — 값 붙여넣기 (감사 추적 불가)
ws["G10"] = 12345.6
```

## 4. 계정과목 강제 정렬

DART 응답은 계정 순서가 회사마다 다르다. 표준 순서로 매핑한 뒤 정렬한다.

```python
PL_ORDER = ["매출액", "매출원가", "매출총이익", "판매비와관리비", "영업이익",
            "영업외손익", "법인세비용", "당기순이익"]
BS_ORDER = ["유동자산", "비유동자산", "자산총계",
            "유동부채", "비유동부채", "부채총계", "자본총계"]
CF_ORDER = ["영업활동현금흐름", "투자활동현금흐름", "재무활동현금흐름"]
```

표준 목록에 없는 계정은 버리지 말고 **해당 재무제표 구분(`sj`) 안에서 원래 순서대로
뒤에 붙인다.** 회사 고유 계정이 사라지면 합계가 안 맞는다.

## 5. 단위와 숫자 서식

```python
SCALE = 1_000_000          # 별도 지시가 없으면 백만 원 단위
# 시트 상단에 "단위: 백만원"을 반드시 적는다.

NUM_FORMATS = {
    "amount":   '#,##0;(#,##0);"-"',   # 음수는 괄호, 0은 대시
    "multiple": '#,##0.0"x"',
    "pct":      '0.0%',
}
```

음수를 괄호로 쓰는 것은 회계 산출물의 표준이다. 0을 `-`로 두면 표가 훨씬 읽힌다.

## 6. 시트 구조

```python
wb = Workbook()
ws = wb.active; ws.title = "요약"      # 분석표가 왼쪽 (메인)
ws_detail = wb.create_sheet("Detail")  # 계정 단위 원본
ws_raw = wb.create_sheet("Raw")        # mydart-mcp 응답 그대로

for sheet in wb.worksheets:
    sheet.sheet_view.showGridLines = False   # 격자선 해제
```

**`Raw` 시트에 도구 응답을 그대로 남긴다.** 나중에 숫자가 의심스러울 때 원본과
대사할 수 있어야 하고, 조회 조건(회사·연도·연결/별도)도 함께 적어 둔다.

---

## 7. 서식 기본값

```python
FONT_NAME = "맑은 고딕"        # 하우스 폰트가 있으면 그것으로 바꾼다

COLORS = {
    "header_dark":  "1F3864",   # 헤더 배경 (네이비)
    "header_light": "D6E4F7",
    "row_alt":      "F2F6FC",
    "total":        "BDD7EE",
    "warn":         "FFF2CC",
}

THIN = Side(style="thin", color="BFBFBF")
MED  = Side(style="medium", color="595959")
```

소속 조직의 하우스 스타일(지정 폰트·테마 컬러)이 있으면 `FONT_NAME`과 `COLORS`만
교체하면 된다. **글자색 규약(2절)은 조직과 무관한 공통 관행이므로 바꾸지 않는다.**

---

## 8. 작성 순서

```
1. 어떤 도구로 무엇을 받을지 정한다 (회사·연도·연결/별도)
2. 받은 JSON을 Raw 시트에 그대로 적는다
3. 계정 매핑·정렬 → Detail 시트
4. Summary는 SUMIFS로 Detail 참조
5. 글자색 규약 적용 → 서식 → 격자선 해제
6. 파일로 저장하고 경로를 알려준다
```

## 9. 자주 하는 실수

- DART 금액을 문자열로 보고 `replace(",", "")` 하기 — **이미 정수다**
- `None`을 `0`으로 바꾸기 — 없는 값과 0은 다르다
- Summary에 계산값 붙여넣기 — 수식으로 연결해야 추적이 된다
- 연결/별도(`fs_div`) 표시 누락 — 어느 쪽 숫자인지 시트에 반드시 적는다
- 5개년을 이어 붙일 때 소급재작성 무시 — 겹치는 해의 차이는 드러내야 한다
