# mydart-mcp

전자공시시스템(DART)을 Claude에서 바로 조회하는 서버.
회사 공시, 재무제표, 그리고 **감사보고서·평가의견서 같은 첨부파일**까지 읽는다.

- **첨부파일을 읽는다** — 감사보고서·외부평가의견서(HWP·PDF). 정작 중요한 내용은 여기 있다
- **OpenDART 83개 API 전부** — 재무제표, 지분공시, 주요사항보고서, 증권신고서
- **폰에서도, 노트북에서도** — 둘 다 된다

---

# 무엇을 물어볼 수 있나

자연어로 물어보면 된다. 회사 고유번호를 찾고 어떤 도구를 쓸지는 알아서 정한다.

**회사·공시**
```
에코프로비엠 개황이랑 최근 공시 정리해줘
셀트리온 작년에 전환사채나 유상증자 한 적 있어?
카카오게임즈 주식대량보유보고서 1년치 주요내용 정리해줘
```

**재무**
```
삼성전자 2025년 연결 손익계산서 표로 만들어줘
네이버 카카오 크래프톤 2025년 실적 비교해줘
현대차 최근 3년 수익성·안정성 지표 추세 정리해줘
컴투스 지난 5년 타법인 출자내역 정리해줘
```

**주주·지배구조**
```
셀트리온 최대주주 현황이랑 변동 이력 정리해줘
에코프로 5% 이상 대량보유 변동 내역 보여줘
삼성전자 임원 보수 상위 5인 보여줘
```

**첨부파일 — 다른 데서 안 되는 것**
```
이 합병 공시 첨부된 외부평가의견서 읽고 합병비율 근거 정리해줘
삼성전자 2025년 사업보고서 첨부 목록 보여줘
연결감사보고서에서 강조사항 문단 찾아줘
```

**엑셀로 받기** — [엑셀 스킬](#엑셀-산출물-스킬-선택)을 함께 설치했을 때
```
삼성전자 3개년 재무제표 뽑아서 엑셀로 만들어줘
네이버·카카오·크래프톤 피어 비교표 만들어줘
```

## Vercel — 폰·웹 어디서나 쓰기

서버를 인터넷에 띄워 커넥터로 붙인다. **각자 자기 것을 띄운다** — 남의 배포를 같이 쓰는 게
아니라, 자기 GitHub 계정에 저장소를 복사해서 자기 Vercel에 올리는 방식이다.
**Vercel 무료 등급으로 된다. 카드도 필요 없다.**

1. **Fork** — 이 저장소 오른쪽 위 **Fork** → **Create fork**.
   내 계정에 똑같은 저장소가 생긴다
2. [vercel.com](https://vercel.com) → **Sign Up** → **Continue with GitHub** → 요금제는 **Hobby**(무료)
3. **Add New… → Project** → 방금 Fork한 저장소를 **Import**
   - 목록에 안 보이면 GitHub 접근을 허용하는 화면이 뜬다 → 허용
   - 환경변수는 **비워 둔다** (인증키는 주소로 준다)
4. **Deploy** → 3분쯤 기다린다
5. 나온 주소를 브라우저로 열어 `mydart-mcp is running`이 보이면 성공
6. [claude.ai](https://claude.ai) → **설정 → 커넥터 → 사용자 지정 커넥터 추가** →
   이름은 아무거나, 주소는 아래

```
https://내가-받은-주소.vercel.app/mcp?key=내_인증키
```

**폰에서는 앱이 아니라 브라우저로** claude.ai에 접속해 등록해야 한다.
앱에는 커넥터를 추가하는 화면이 없다. 한 번 등록하면 앱에도 따라온다.

**업데이트** — 원본 저장소가 바뀌면 내 Fork에서 **Sync fork**를 누른다.
그러면 Vercel이 알아서 다시 배포한다.

> **주소가 곧 열쇠다.** 인증키가 주소에 들어 있으니 그 주소를 남에게 주지 않는다.
> 새면 OpenDART에서 재발급하고 커넥터 주소만 바꾸면 된다.
> 서버는 키를 저장하지 않고 요청 때 받은 것을 그 요청 동안만 쓴다.

# 첨부파일 읽기

DART 공시는 "본문 + 첨부" 구조다. **감사보고서·외부평가의견서·계약서처럼 정작 중요한 내용은 첨부에 있다.**
그런데 OpenDART API에는 첨부 엔드포인트가 없어서, API만 감싼 서버들은 이걸 못 한다.

```
list_attachments(rcept_no="20260310002820")
  → 본문, 감사보고서, 연결감사보고서, 내부회계관리제도운영보고서, 정관 …

read_attachment(rcept_no="20260310002820", filename="연결감사보고서")
  → {"format": "pdf", "total_chars": 112214, "text": "..."}
```

지원 형식은 **HWP(5.0), HWPX, PDF, 텍스트/HTML/XML**. 그 밖의 형식은 다운로드 링크만 준다.
HWP는 파이썬에 쓸 만한 경량 라이브러리가 없어(`pyhwp`는 AGPL) 파서를 직접 넣었다.

## 지켜야 할 선

`dart.fss.or.kr/robots.txt`는 뷰어와 다운로드 경로를 크롤러에 대해 Disallow로 둔다. 그래서

- **사용자가 접수번호로 지목한 단일 공시**에만 접근한다. 목록을 훑으며 긁어모으지 않는다
- User-Agent에 `mydart-mcp/<버전>`을 그대로 노출한다. 브라우저를 사칭하지 않는다
- 첨부 30MB, 압축 해제 200MB를 넘으면 받지 않고 링크만 준다

공시 본문과 재무 데이터는 언제나 공식 API를 쓴다. 스크래핑은 첨부에만 쓴다.

# 엑셀 산출물 스킬 (선택)

`skills/dart-excel-report/`에 스킬이 하나 함께 들어 있다. DART 데이터를 **감사 추적이 가능한 엑셀**로
옮기는 코드를 작성하게 한다.

- **글자색이 곧 출처다** — 검정=수식, 빨강=원본 데이터, 노랑=가정, 초록=타시트 참조
- **Summary는 Detail을 `SUMIFS`로 참조한다** — 값을 붙여넣지 않는다
- **계정과목을 표준 순서로 정렬한다** — DART는 회사마다 계정 순서가 다르다

## 설치

MCP와 별개라 따로 넣어야 한다. `.mcpb`에는 들어 있지 않다.

1. 이 저장소 → 초록색 **Code** → **Download ZIP** → 압축 해제
2. 그 안의 **`skills\dart-excel-report` 폴더만** 따로 압축한다
   (폴더 우클릭 → 압축 → `dart-excel-report.zip`)
3. [claude.ai](https://claude.ai) → **설정 → Skills** → 그 ZIP을 업로드

계정에 올리는 방식이라 **한 번 올리면 모든 기기에 따라온다.** PC를 바꿔도 그대로다.
`지금 쓸 수 있는 스킬 목록 보여줘`로 확인할 수 있다.

# 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 커넥터 등록이 "로그인 서비스에 등록할 수 없습니다"로 실패 | 배포가 옛 버전이다. Vercel에서 최신 커밋이 **Ready**인지 확인하고 커넥터를 지웠다 다시 추가한다 |
| 설정 → 개발자에 `mydart`가 없다 | 거의 항상 **Microsoft Store 버전 Claude**다. 위 「확장 파일」의 주의를 참고 |
| `Could not attach to MCP server` | 확장 파일 방식(uv 런타임)이 아직 실험 단계라 Claude Desktop 버전에 따라 안 될 수 있다. **Vercel 방식을 쓰는 게 가장 빠르다.** 굳이 노트북에 깔아야 하면 **Code → Download ZIP** 후 `pyproject.toml`이 보이는 폴더에서 `powershell -ExecutionPolicy Bypass -File .\install.ps1` |
| `ConnectError` / `ProxyError` | 사내 방화벽이 `opendart.fss.or.kr` 또는 `dart.fss.or.kr`을 막고 있다 |
| `오류 [020]` / `[010]` | `020`은 일일 20,000건 초과, `010`은 등록되지 않은 인증키 |
| 응답이 느리다 | 첫 조회는 기업 목록을 받느라 느리다. 주가를 물으면 DART에 없는 정보라 웹을 뒤진다 |

# 개발

```bash
uv sync --group dev
uv run pytest
uv run mydart-mcp-http                          # 원격 방식으로 로컬 실행
npx @anthropic-ai/mcpb pack . mydart-mcp.mcpb   # 확장 파일 빌드
```

환경변수: `DART_API_KEY`(필수), `MYDART_CACHE_DIR`(기본 `~/.cache/mydart-mcp`).
원격으로 띄우면 인증키를 주소에서 받아 **그 요청 동안만** 쓴다. 전역에 담으면 한 사람의 키가
다음 사람 요청에 딸려 나갈 수 있어, 요청 단위로 갈리는 `ContextVar`에 담고 테스트로 고정해 두었다.

## 알아둘 점

- 기업 고유번호 10만 건은 7일마다 새로 받는다. 파싱 결과를 JSON으로 캐시한다(1.58초 → 0.13초).
- 인증키는 로그에 찍히지 않도록 가린다. OpenDART가 키를 URL 쿼리로 받기 때문에 필요한 조치다.
- 서버리스는 lifespan을 보장하지 않고 MCP 세션 관리자는 인스턴스당 한 번만 시작되므로,
  원격에서는 요청마다 앱을 세우고 버린다.
- 실물 DART로 확인된 범위는 공시검색·고유번호·재무제표·첨부목록·첨부추출과 원격 배포다.
  나머지 API는 아직 실제 응답으로 확인되지 않았다. 오류를 만나면 메시지를 그대로 보고하면 된다.
